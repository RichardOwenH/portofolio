Analytics case study / System activity monitoring

System Monitoring

A Power BI dashboard for reviewing weekly summaries, user-login activity, and work-order records.

Context

Internship project at PT Mattel Indonesia focused on monitoring recurring system activity.

Business Problem

System records and user activity needed to be consolidated into a clearer monitoring view.

Objective

Provide a Power BI dashboard for reviewing weekly summaries, user-login activity, and system records.

Analysis Coverage

Weekly summaries, user-login monitoring, and work-order-related information.

Selected Dashboard Views

Decision Support

Helped users review recurring system activity and identify records needing further attention.

Business Impact

Provided a centralized view of recurring system-monitoring information.

Tools

Power BI.
